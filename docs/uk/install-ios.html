Встановіть Reset Moto Reminders на iPhone.

Скористайтеся готовою IPA або зберіть застосунок самостійно в Xcode. Обидва варіанти використовують ваш Apple Account і не потребують платного членства розробника.

Завантажити застосунок для iPhone (.ipa)Зібрати самостійно

Безкоштовний Apple Account підписує застосунок на сім днів. Повторіть встановлення після завершення строку.

Найпростіший варіант

Встановіть IPA через AltServer

  1. Завантажте IPA

    Скористайтеся кнопкою вище. Також можна завантажити контрольну суму SHA-256.

  2. Встановіть AltServer

    Скористайтеся офіційною інструкцією для Mac або Windows.

  3. Під’єднайте iPhone

    Під’єднайте та розблокуйте iPhone, потім підтвердьте запит довіри.

  4. Встановіть IPA

    Утримуйте Option на Mac або Shift у Windows під час натискання піктограми AltServer. Виберіть Sideload .ipa…, виберіть завантажений файл і виконайте підказки щодо підпису.

  5. Дозвольте застосунок

    Якщо буде запит, увімкніть Параметри → Приватність і безпека → Режим розробника. Потім відкрийте Параметри → Загальні → VPN і керування пристроєм і довіртеся сертифікату застосунку розробника.

Альтернатива

Зберіть самостійно в Xcode

  1. Завантажте код

    Завантажити й розпакувати пакет коду для iPhone.

  2. Відкрийте проєкт

    Відкрийте ios/ResetMotoReminders/ResetMotoReminders.xcodeproj у Xcode.

  3. Виберіть обліковий запис

    У Signing & Capabilitiesвиберіть свою Personal Team. За потреби змініть ідентифікатор пакета на унікальний.

  4. Запустіть на iPhone

    Під’єднайте й розблокуйте iPhone, виберіть його в Xcode та натисніть Run.

Reset Moto Reminders не отримує дані вашого Apple Account. AltServer або Xcode виконує підпис локально.
