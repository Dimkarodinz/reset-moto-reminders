Installez Reset Moto Reminders sur iPhone.

Utilisez l’IPA prête à l’emploi ou compilez vous-même l’application avec Xcode. Les deux options utilisent votre propre compte Apple et ne nécessitent aucun abonnement développeur payant.

Télécharger l’application iPhone (.ipa)Compiler vous-même

Un compte Apple gratuit signe l’application pour sept jours. Répétez l’installation après expiration.

Option la plus simple

Installer l’IPA avec AltServer

  1. Téléchargez l’IPA

    Utilisez le bouton ci-dessus. Vous pouvez aussi télécharger sa somme SHA-256.

  2. Installez AltServer

    Suivez le guide officiel pour Mac ou Windows.

  3. Connectez l’iPhone

    Connectez et déverrouillez l’iPhone, puis acceptez la demande de confiance.

  4. Installez l’IPA

    Maintenez Option sur Mac ou Shift sous Windows tout en cliquant sur l’icône AltServer. Choisissez Sideload .ipa…, sélectionnez le fichier téléchargé puis suivez les instructions de signature.

  5. Autorisez l’application

    Si nécessaire, activez Réglages → Confidentialité et sécurité → Mode développeur. Ouvrez ensuite Réglages → Général → VPN et gestion de l’appareil et approuvez votre certificat d’application développeur.

Alternative

Compiler vous-même avec Xcode

  1. Téléchargez le code source

    Télécharger et extraire le paquet source iPhone.

  2. Ouvrez le projet

    Ouvrez ios/ResetMotoReminders/ResetMotoReminders.xcodeproj dans Xcode.

  3. Sélectionnez votre compte

    Dans Signing & Capabilities, sélectionnez votre équipe personnelle. Si nécessaire, remplacez l’identifiant de bundle par une valeur unique.

  4. Exécutez sur l’iPhone

    Connectez et déverrouillez l’iPhone, sélectionnez-le dans Xcode puis appuyez sur Run.

Reset Moto Reminders ne reçoit pas les identifiants de votre compte Apple. AltServer ou Xcode effectue la signature localement.

Connectez-vous à la moto

Alimentez le vLinker MC+ depuis la moto, laissez le contact mis et le moteur arrêté, ouvrez l’application, autorisez le Bluetooth puis touchez Connecter. Lisez la moto avant de réinitialiser le rappel ou d’effacer les DTC.
