Android 8 ou version ultérieure

Installez Reset Moto Reminders sur Android.

La version 0.8.0 lit les informations de la moto et les DTC, réinitialise le rappel d’entretien et propose l’effacement des DTC en Bêta.

Télécharger l’APKCompiler depuis le code source

L’effacement des DTC est en Bêta. Lisez et notez les codes avant de les effacer. Effacer un code ne répare pas la panne.

Contrôles de la version

Étiquette source

L’APK est compilée depuis l’étiquette publique android-v0.8.0 .

Signature du projet

L’APK est signée avec la clé de publication Reset Moto Reminders. SHA-256 du certificat : 2fdf4e70…1eb50ad6.

Somme de contrôle

La version contient une somme de contrôle SHA-256 de l’APK.

Installer

  1. Téléchargez l’APK

    Utilisez le bouton ci-dessus. Téléchargez aussi la somme de contrôle si vous souhaitez vérifier le fichier.

  2. Vérifiez la somme

    Sur Mac, exécutez shasum -a 256 filename.apk et comparez le résultat au fichier de somme de contrôle de la version.

  3. Autorisez cette installation

    Ouvrez l’APK sur Android. Si Android le demande, autorisez votre navigateur ou gestionnaire de fichiers à installer des applications inconnues, installez Reset Moto Reminders puis désactivez à nouveau cette autorisation.

  4. Associez l’adaptateur

    Alimentez le vLinker MC+ depuis la moto. Dans les réglages Bluetooth Android, associez vLinker MC-Android avec le code PIN 1234, puis revenez dans l’application et connectez-vous.
