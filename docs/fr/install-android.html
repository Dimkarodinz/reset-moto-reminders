Installer Reset Moto Reminders sur Android

La version 0.10.0 lit les informations de la moto et les DTC, réinitialise le rappel d’entretien et propose l’effacement des DTC en Bêta

Télécharger l’APKCompiler depuis le code source

L’effacement des DTC est en Bêta. Lisez et notez les codes avant de les effacer. Effacer un code ne répare pas la panne.

Contrôles de la version

Étiquette source

L’APK est compilée depuis l’étiquette publique android-v0.10.0 .

Signature du projet

L’APK est signée avec la clé de publication Reset Moto Reminders.

Installer

  1. Téléchargez l’APK

    Utilisez le bouton ci-dessus.

  2. Autorisez cette installation

    Ouvrez l’APK sur Android. Si Android le demande, autorisez votre navigateur ou gestionnaire de fichiers à installer des applications inconnues, installez Reset Moto Reminders puis désactivez à nouveau cette autorisation.

  3. Branchez l’adaptateur

    Pour vLinker, associez vLinker MC-Android dans les paramètres Bluetooth Android avec le PIN 1234. Pour l’OBDLink MX original, appuyez sur son bouton Connect et associez OBDLink MX dans les paramètres Android. OBDLink CX est détecté et associé depuis l’application.

La prise en charge d’OBDLink CX et de l’OBDLink MX original est expérimentale jusqu’à l’essai physique de chaque adaptateur avec la Tiger 900. Le MX original fonctionne uniquement sous Android.
