Confidentialité

Sans compte. Sans analyse. Sans envoi.

Les applications principales Reset Moto Reminders pour Android et iPhone fonctionnent localement entre le téléphone, l’adaptateur Bluetooth et la moto.

Données non collectées

Ce projet ne collecte aucun compte, nom, adresse e-mail, position, VIN, identifiant publicitaire, analyse d’usage ou rapport de diagnostic dans le cloud.

Diagnostics locaux

Les applications peuvent produire des événements de diagnostic locaux limités pour le développement. Les adresses Bluetooth sont exclues et les données de sécurité masquées. L’application principale ne permet ni partage ni envoi.

Site web

Ce site GitHub Pages statique n’utilise ni cookies, analyse, formulaire ni JavaScript personnalisé. GitHub peut traiter les données ordinaires des requêtes d’hébergement selon sa propre politique de confidentialité.

Liens externes

GitHub, Apple et Ko-fi sont des services distincts appliquant leurs propres règles de confidentialité. En suivant ces liens, vous quittez ce site statique.
