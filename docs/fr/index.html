Réinitialisez les rappels d’entretien sur les motos Triumph compatibles

L’application relie votre téléphone à la moto avec un adaptateur OBD Bluetooth compatible pour réinitialiser la date et la distance d’entretien, lire les codes de défaut et les effacer à votre demande

Sans compte, abonnement, publicité, passage en concession ni réglage de l’ECU

Installation Android Installation iPhone

À quoi sert l’application ?

Après avoir entretenu la moto vous-même ou dans un atelier indépendant, le tableau de bord peut continuer à afficher l’avertissement d’entretien. Reset Moto Reminders permet de terminer l’opération sans payer une concession ni un abonnement annuel à une application de diagnostic.

L’application lit aussi les codes de défaut moteur (DTC), explique clairement les codes connus et peut effacer les codes mémorisés après leur lecture. Effacer un code ne répare pas la panne qui l’a provoqué.

Matériel nécessaire

  • Un téléphone Android ou un iPhone.
  • Adaptateurs compatibles : vLinker MC+ et OBDLink CX. OBDLink MX, LX et MX+ sont expérimentaux sous Android.

Comment l’utiliser

  1. Branchez l’adaptateur

    Branchez l’adaptateur OBD Bluetooth au port de diagnostic de la moto. Mettez le contact en laissant le moteur arrêté.

  2. Connectez le téléphone

    Pour vLinker sur Android, associez vLinker MC-Android dans les paramètres Bluetooth avec le PIN 1234. Pour OBDLink MX, LX ou MX+, appuyez sur Connect et associez le nom exact du produit dans les paramètres Android. vLinker MC-IOS et OBDLink CX se connectent depuis l’application.

  3. Sélectionner et lire

    Sélectionnez votre moto exacte, touchez Connecter, puis utilisez Lire la moto si cette option est disponible. Vérifiez que les informations affichées sont plausibles avant une écriture.

  4. Choisissez une opération

    Lisez les codes de défaut, effacez les codes affichés ou définissez la prochaine distance et date d’entretien. L’application demande une confirmation avant toute modification.

  5. Vérifiez au tableau de bord

    Après une réinitialisation, vérifiez la date et la distance d’entretien sur la moto. Après un effacement, relisez les codes.

OBDLink CX est expérimental jusqu’à un essai physique. OBDLink MX, LX et MX+ sont expérimentaux et réservés à Android.

Pourquoi utiliser cette application ?

  • Ciblée : elle réinitialise le rappel d’entretien et lit ou efface les DTC. Elle ne règle, ne flashe, ne reprogramme et ne code pas l’ECU.
  • Sans coût récurrent : l’application ne comporte ni compte, abonnement, publicité, analyse d’usage ni fonction payante.
  • Vérifiable : le code complet de l’application et les profils moto sont publiés sur GitHub sous une licence non commerciale à code accessible.
  • Écritures prudentes : l’application contrôle les réponses attendues de l’adaptateur et de la moto, demande confirmation, envoie une seule écriture et ne réessaie pas automatiquement après un résultat incertain.

Téléchargement et installation

Android utilise une APK publiée dans les versions GitHub du projet. Sur iPhone, utilisez l’IPA prête pour la signature locale ou le projet Xcode public à compiler vous-même ; les installations gratuites durent sept jours.
