Reset Moto Reminders auf Android installieren.

Version 0.8.0 liest Motorraddaten und DTCs aus, setzt die Serviceerinnerung zurück und enthält das Löschen von DTCs als Beta-Funktion.

APK herunterladenAus dem Quellcode bauen

DTC-Löschen ist Beta. Lesen und notieren Sie die Codes vor dem Löschen. Das Löschen eines Codes behebt den Fehler nicht.

Release-Prüfungen

Quellcode-Tag

Die APK wurde aus dem öffentlichen android-v0.8.0 Tag gebaut.

Projektsignatur

Die APK ist mit dem Release-Schlüssel von Reset Moto Reminders signiert. Zertifikat-SHA-256: 2fdf4e70…1eb50ad6.

Prüfsumme

Das Release enthält eine SHA-256-Prüfsumme für die APK.

Installieren

  1. APK herunterladen

    Verwenden Sie die Schaltfläche oben. Laden Sie auch die Prüfsumme herunter, wenn Sie die Datei verifizieren möchten.

  2. Prüfsumme verifizieren

    Führen Sie auf einem Mac shasum -a 256 filename.apk aus und vergleichen Sie das Ergebnis mit der Prüfsummendatei des Releases.

  3. Diese Installation erlauben

    Öffnen Sie die APK unter Android. Falls Android fragt, erlauben Sie Ihrem Browser oder Dateimanager die Installation unbekannter Apps, installieren Sie Reset Moto Reminders und deaktivieren Sie die Berechtigung anschließend wieder.

  4. Adapter koppeln

    Versorgen Sie den vLinker MC+ über das Motorrad mit Strom. Koppeln Sie in den Android-Bluetooth-Einstellungen vLinker MC-Android mit der PIN 1234, kehren Sie dann zur App zurück und verbinden Sie sich.
