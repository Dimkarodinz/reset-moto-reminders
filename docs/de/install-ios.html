Reset Moto Reminders auf dem iPhone installieren

Verwenden Sie die fertige IPA oder erstellen Sie die App selbst mit Xcode; beide Optionen verwenden Ihren eigenen Apple Account und erfordern keine kostenpflichtige Entwickler-Mitgliedschaft

iPhone-App herunterladen (.ipa)Selbst erstellen

Mit einem kostenlosen Apple Account wird die App für sieben Tage signiert. Wiederholen Sie die Installation nach Ablauf.

Einfachste Option

IPA mit AltServer installieren

  1. IPA herunterladen

    Verwenden Sie die Schaltfläche oben. Sie können auch die SHA-256-Prüfsumme herunterladen.

  2. AltServer installieren

    Folgen Sie der offiziellen Mac-Anleitung oder Windows-Anleitung.

  3. iPhone verbinden

    Verbinden und entsperren Sie das iPhone und bestätigen Sie anschließend die Vertrauensabfrage.

  4. IPA installieren

    Halten Sie Option auf dem Mac oder Shift unter Windows gedrückt, während Sie auf das AltServer-Symbol klicken. Wählen Sie Sideload .ipa…, wählen Sie die heruntergeladene Datei und folgen Sie den Signierhinweisen.

  5. App erlauben

    Aktivieren Sie bei Aufforderung Einstellungen → Datenschutz & Sicherheit → Entwicklermodus. Öffnen Sie anschließend Einstellungen → Allgemein → VPN und Geräteverwaltung und vertrauen Sie Ihrem Entwickler-App-Zertifikat.

Alternative

Mit Xcode selbst erstellen

  1. Quellcode herunterladen

    iPhone-Quellcodepaket herunterladen und entpacken.

  2. Projekt öffnen

    Öffnen Sie ios/ResetMotoReminders/ResetMotoReminders.xcodeproj in Xcode.

  3. Konto auswählen

    Wählen Sie unter Signing & CapabilitiesIhr Personal Team aus. Ändern Sie bei Bedarf die Bundle-ID in einen eindeutigen Wert.

  4. Auf dem iPhone ausführen

    Verbinden und entsperren Sie das iPhone, wählen Sie es in Xcode aus und drücken Sie Run.

Reset Moto Reminders erhält Ihre Apple-Account-Anmeldedaten nicht. AltServer oder Xcode übernimmt die Signierung lokal.

Mit dem Motorrad verbinden

Versorgen Sie den vLinker MC+ oder OBDLink CX über das Motorrad mit Strom, lassen Sie die Zündung ein und den Motor aus, öffnen Sie die App, erlauben Sie Bluetooth und tippen Sie auf Verbinden. Lesen Sie das Motorrad aus, bevor Sie die Erinnerung zurücksetzen oder DTCs löschen.

Die OBDLink-CX-Unterstützung ist experimentell, bis ein praktischer Test mit CX und Tiger 900 abgeschlossen ist.
