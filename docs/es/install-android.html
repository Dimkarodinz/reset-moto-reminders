Comprobaciones de la versión

Etiqueta del código

La APK se compila desde la etiqueta pública android-v0.8.0 .

Firma del proyecto

La APK está firmada con la clave de publicación de Reset Moto Reminders. SHA-256 del certificado: 2fdf4e70…1eb50ad6.

Suma de comprobación

La versión incluye una suma SHA-256 de la APK.

Instalar

  1. Descarga la APK

    Usa el botón anterior. Descarga también la suma de comprobación si quieres verificar el archivo.

  2. Verifica la suma

    En un Mac, ejecuta shasum -a 256 filename.apk y compara el resultado con el archivo de suma de comprobación de la versión.

  3. Permite esta instalación

    Abre la APK en Android. Si Android lo solicita, permite que el navegador o gestor de archivos instale aplicaciones desconocidas, instala Reset Moto Reminders y vuelve a desactivar el permiso.

  4. Empareja el adaptador

    Alimenta el vLinker MC+ desde la moto. En los ajustes de Bluetooth de Android, empareja vLinker MC-Android con el PIN 1234, vuelve a la aplicación y conéctate.
