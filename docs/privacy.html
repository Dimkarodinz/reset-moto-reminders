Privacy

No account. No analytics. No upload.

The Reset Moto Reminders main Android and iPhone applications operate locally between your phone, Bluetooth adapter and motorcycle.

Data not collected

No account, name, email address, location, VIN, advertising identifier, usage analytics or cloud diagnostic report is collected by this project.

Local diagnostics

The apps may produce bounded local diagnostic events for development. They exclude Bluetooth addresses and redact security payloads. The main app has no sharing or upload feature.

Website

This static GitHub Pages site has no cookies, analytics, forms or custom JavaScript. GitHub may process ordinary hosting request data under GitHub's own privacy statement.

External links

GitHub, Apple and Ko-fi are separate services with their own privacy practices. Following those links leaves this static site.
