Install

  1. Download the APK

    Use the button above.

  2. Allow this one installation

    Open the APK on Android. If Android asks, allow your browser or file manager to install unknown apps, install Reset Moto Reminders, then disable that permission again.

  3. Connect the adapter

    For vLinker, pair vLinker MC-Android in Android Bluetooth settings with PIN 1234. OBDLink CX is found and paired from inside the app.

OBDLink CX support is experimental until a physical CX and Tiger 900 test is completed.
