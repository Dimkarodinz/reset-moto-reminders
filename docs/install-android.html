What the official release will include

Immutable source tag

The APK source will be the exact public Git tag named in the release.

Project signature

The APK will be signed with the protected Reset Moto Reminders release key, not Android's debug key. Certificate SHA-256: 2fdf4e70…1eb50ad6.

SHA-256 checksum

The release will include a checksum file so the downloaded bytes can be independently verified.

When a release is available

  1. Download only from GitHub Releases

    Open the latest release from this site's button and download the APK plus its checksum. Avoid third-party mirrors.

  2. Verify the checksum

    On a Mac, run shasum -a 256 filename.apk and compare the result with the release's checksum file.

  3. Allow this one installation

    Open the APK on Android. If Android asks, allow your browser or file manager to install unknown apps, install Reset Moto Reminders, then disable that permission again.

  4. Pair the adapter

    Power the vLinker MC+ from the motorcycle. In Android Bluetooth settings, pair vLinker MC-Android using PIN 1234, then return to the app and connect.
