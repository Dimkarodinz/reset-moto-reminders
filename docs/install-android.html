DTC clear is Beta. Read and record the codes before clearing them. Clearing a code does not repair the fault.

Checksum

The release includes a SHA-256 checksum for the APK.

Install

  1. Download the APK

    Use the button above. Download the checksum too if you want to verify the file.

  2. Verify the checksum

    On a Mac, run shasum -a 256 filename.apk and compare the result with the release's checksum file.

  3. Allow this one installation

    Open the APK on Android. If Android asks, allow your browser or file manager to install unknown apps, install Reset Moto Reminders, then disable that permission again.

  4. Pair the adapter

    Power the vLinker MC+ from the motorcycle. In Android Bluetooth settings, pair vLinker MC-Android using PIN 1234, then return to the app and connect.
