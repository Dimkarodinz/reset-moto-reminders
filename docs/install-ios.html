Install Reset Moto Reminders on iPhone.

Use the ready-made IPA, or build the app yourself with Xcode. Both options use your own Apple Account and require no paid developer membership.

Easiest option

Install the IPA with AltServer

  1. Download the IPA

    Use the button above. You can also download its SHA-256 checksum.

  2. Install AltServer

    Follow the official Mac guide or Windows guide.

  3. Connect the iPhone

    Connect and unlock the iPhone, then accept the Trust prompt.

  4. Sideload the IPA

    Hold Option on Mac or Shift on Windows while clicking the AltServer icon. Choose Sideload .ipa…, select the downloaded file, then follow the signing prompts.

  5. Allow the app

    If asked, enable Settings → Privacy & Security → Developer Mode. Then open Settings → General → VPN & Device Management and trust your Developer App certificate.

Alternative

Build it yourself with Xcode

  1. Download the source

    Download and extract the iPhone source package.

  2. Open the project

    Open ios/ResetMotoReminders/ResetMotoReminders.xcodeproj in Xcode.

  3. Select your account

    In Signing & Capabilities, select your Personal Team. If needed, change the bundle identifier to something unique.

  4. Run on the iPhone

    Connect and unlock the iPhone, select it in Xcode, and press Run.

Reset Moto Reminders does not receive your Apple Account credentials. AltServer or Xcode handles signing locally.

Connect to the motorcycle

Power the vLinker MC+ from the motorcycle, keep the ignition on and engine off, open the app, allow Bluetooth access, and tap Connect. Read the motorcycle before resetting the reminder or clearing DTCs.
