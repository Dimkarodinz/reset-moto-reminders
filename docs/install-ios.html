iPhone · free local signing

Install with Xcode in about ten minutes.

You need a Mac, an iPhone running iOS 16 or later, Xcode, and any Apple Account. No paid Apple Developer membership is required. A free install expires after seven days and can be rebuilt the same way.

There is intentionally no shared IPA. You sign the public Xcode project locally with your own Apple Account. Never send your Apple password, certificate, device ID or provisioning profile to this project.

  1. Install Xcode

    Install the current Xcode from the Mac App Store. Open it once and allow its requested components to finish installing.

  2. Download and open the project

    Download the iPhone source ZIP from the latest release and extract it. Open ios/ResetMotoReminders/ResetMotoReminders.xcodeproj.

  3. Add your Apple Account

    In Xcode, open Xcode → Settings → Accounts, add your Apple Account, then return to the project.

  4. Select your signing team

    Select the blue ResetMotoReminders project, select the app target, then open Signing & Capabilities. Leave Automatically manage signing enabled and select your Personal Team. If the bundle identifier is unavailable, replace dev.resetlight.ios with something unique such as com.yourname.resetmotoreminders.

  5. Connect and trust the iPhone

    Connect the unlocked iPhone to the Mac with a cable. Tap Trust on the iPhone if asked, enter the device passcode, and select the iPhone as the Xcode run destination.

  6. Build and install

    Press the triangular Run button in Xcode. If the iPhone asks for Developer Mode, open Settings → Privacy & Security → Developer Mode, enable it, restart, and confirm.

  7. Trust the developer certificate if asked

    If iOS says the developer app is untrusted, open Settings → General → VPN & Device Management, select the Developer App entry for your Apple Account, and choose Trust. Run the app again.

  8. Connect to the motorcycle

    Power the vLinker MC+ from the motorcycle, keep ignition on and engine off, open Reset Moto Reminders, allow Bluetooth access, and select Connect. Read the motorcycle before attempting a reset or DTC clear.

Free Personal Team provisioning expires after seven days. Reconnect the iPhone, reopen the same Xcode project and press Run again. Your app data may be replaced during reinstall, so always rely on the motorcycle read-back rather than app history.

Troubleshooting

If Xcode will not install the app

The iPhone is not listed in Xcode

Unlock it, reconnect the cable, accept the Trust prompt on both devices, and use Xcode's device window to wait for pairing to finish.

The bundle identifier is unavailable

Use any reverse-domain identifier unique to your Apple Account, for example com.yourname.resetmotoreminders. This does not change the app name shown on the phone.

“Developer App certificate is not trusted”

On the iPhone, open Settings → General → VPN & Device Management, select your Developer App certificate, and trust it.

Will the project see my Apple Account?

No. Xcode handles local signing. The repository and application do not receive or transmit your Apple Account credentials, signing certificate, provisioning profile, or iPhone identifier.
